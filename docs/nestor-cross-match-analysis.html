What the clusters mean
Auth gate is one problem, not two
the-squirrel (30 files) and law-gazelle (1 chokepoint) cluster at 0.523 — highest in the dataset. Both reach into _SIGNED_FIELDS. One AuthGate Protocol solves both, but law-gazelle is the easier first target.
safe_integration is a tight triangle
17-copies, orphaned-copies, and three-contracts form a strongly connected triangle (0.43–0.46). The matcher confirms what the audit found: the copy count, the dead code, and the contract conflation are the same problem from three angles. Fix the contracts, the copies and orphans resolve.
Two sys.path imports want the same fix
SoilClient and llm_router cluster at 0.444 — both use identical sys.path.insert(0, willow_root) bootstrap. A shared import-resolution pattern handles both.
Solved abstractions already form a family
willow-read, willow-pg, and the MCP client connections cluster together cross-layer. The matcher sees these as structurally similar — the already-solved problems share vocabulary and shape with the unsolved ones. The template is there.
The invisible things cluster
jarvis (JS client, invisible to grep), llmphysics (.js manifest), and game-lab (no manifest) form a cross-layer cluster. Shared trait: invisible to standard scan tooling. These are the things an audit misses and Nestor caught by vocabulary overlap.
Manifest store_scope has a clear path
store_scope declarations and story-timeline's capability format cluster at 0.464. The evolutionary path is already defined: from bare prefixes to named abstract capabilities. story-timeline is the template.

Decision signals
P0 is confirmed: safe_integration
The safe_integration triangle (3 findings, all mutually connected at 0.41–0.46) is the densest cluster. 17 copies, 11 orphaned, 3 conflated contracts. The matcher agrees with the roadmap: this is the highest-leverage fix.
P1 template already exists
ask-jeles's generic MCP client connects cross-layer to the pluggability template (0.369). The solved-abstractions cluster (willow-read + willow-pg + MCP clients) proves the extraction pattern works. Don't design from scratch.
Auth gate needs sequencing
0.523 affinity between the-squirrel and law-gazelle, but law-gazelle is a single chokepoint vs 30-file fan-out. Do gazelle first as the AuthGate Protocol prototype, then tackle squirrel.
The ai-game-master bug is real
L4-bug connects to both dead-stubs (0.365) and auth-gate-gazelle (0.363) — three silent permission failures in the same subsystem. Fix the type error immediately, investigate the pattern.
The invisible cluster is a scan gap
jarvis + llmphysics + game-lab cluster not by coupling type but by invisibility to standard tooling. Any future audit that only greps Python will miss these. Add JS manifest scanning and no-manifest detection.
49% agnostic validates the approach
willow-pg's connection to already-agnostic (0.398) and gold-standard (0.378) confirms: abstractions that exist and are used actually decouple. The remaining 51% is extraction, not invention.
