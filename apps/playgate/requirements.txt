# Stdlib-only core — no runtime dependencies.
#
# Persistence resolves through the shared libs/vault-paths (installed with
# `pip install -e libs/vault-paths` in dev/CI, same as the other apps in the
# app-tests matrix). Only playgate/paths.py imports it, and a test enforces
# that: vault_root() is a security boundary, so a second importer would be a
# second place for it to drift. paths.py falls back to the in-repo source tree
# when the library is not installed.
#
# tests/test_no_egress.py::test_import_is_stdlib_only keeps the four core
# modules — catalog, disposition, install, interruption — free of it, and of
# everything else third-party.
#
# Dev-only, not a runtime dependency:
# pytest>=8.0
#
# Test-only, not a runtime dependency:
# nestor — walks the disposition hash chain (playgate/audit.py). Injected: the
# core writes `prev` with stdlib hashlib and `serve` runs without nestor
# installed; only `playgate verify` needs it, and it says so rather than
# guessing when it is absent. Pinned in store-ci.yml's app-tests matrix:
#   pip install "git+https://github.com/rudi193-cmd/Nestor@v0.2.0"
# The chain tests importorskip it, so that leg also sets
# PLAYGATE_REQUIRE_NESTOR=1 to turn a silent skip into a failure.
