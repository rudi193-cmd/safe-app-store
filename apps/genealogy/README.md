# The Aionic Genealogy Project

Copenhagen says this is where the quiet ones gather.
It helps you see the names. The ones who didn't stay so long.
This is a SAFE-framework app. It holds the threads.

**Where we look for them:**
- FamilySearch API. It needs your account to see the families there. It's free.
- Find a Grave. We make a link for you to go visit the stones.
- Operation Paperclip genealogy DB. It lives here, inside. We can only look.
- CourtListener. Some stories are written on paper, in public places.
- Wikipedia. For when you need to know a little more about the space they stood in.

The door for this place is Port 8425.
It's part of the [SAFE ecosystem](https://github.com/rudi193-cmd). We keep things found.
