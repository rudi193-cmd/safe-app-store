# oracle-text

Readings written by a Tracery grammar, every branch picked by the seeded stream, so each one can be replayed.

A willow add-on, and it stays in willow: Die-Namic plays it there, pinned by its files' hashes ([../../willow.pin.json](../../willow.pin.json)). Its card, with everything it does and refuses: [oracle-text in willow](https://github.com/willow-memory/Willow/tree/9d7c45b0d1ab64e5c07519ec6bbb42489ebb19b1/adapters/stdlib/oracle-text).

## Playing it

```
python apps/game/games/play.py oracle-text --seed TEXT [--grammar FILE] [--count N] [--origin NAME]
```

It reads no box: it takes its arguments alone.

It writes nothing: no row, no file.
