# play-bureau

bureau, the Bureaucracy homage at UTETY, on the record: the deadlock proved, every visit a row, and Gerald's napkin the only way out.

A willow add-on, and it stays in willow: Die-Namic plays it there, pinned by its files' hashes ([../../willow.pin.json](../../willow.pin.json)). Its card, with everything it does and refuses: [play-bureau in willow](https://github.com/willow-memory/Willow/tree/dd1e406d66d07fd6397e41880da831e74bbe9696/adapters/stdlib/play-bureau).

## Playing it

```
python apps/game/games/play.py play-bureau --table DIR new
python apps/game/games/play.py play-bureau --table DIR go pigeon
python apps/game/games/play.py play-bureau --table DIR hand hanz
python apps/game/games/play.py play-bureau --table DIR wait
python apps/game/games/play.py play-bureau --table DIR look
python apps/game/games/play.py play-bureau --table DIR quit
python apps/game/games/play.py play-bureau prove
python apps/game/games/play.py play-bureau --table DIR check
```

On a box laid by `box/open_table.py`, `--table DIR` plays on its record.

Each move is a row on the record carrying bureau's state, through the kernel. `prove` reads no box.

## Where it came from

bureau, from apps/bureau in this store, which keeps its web docket and its ledger: its building, goo, napkin and proof carried word for word, and played against bureau's own Session on 79,973 moves, all the same. The lore is Sean's.
