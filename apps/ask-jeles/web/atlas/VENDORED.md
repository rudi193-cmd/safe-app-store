## What we changed (and only this)

The upstream engine and data are untouched. Our changes are additive and
cosmetic, so future upstream syncs stay easy:

1. `index.html` — retitled to "The Catalog"; rebranded the header
   (`Atlas of Knowledge / Constellations of Learning` → `The Catalog /
   The Stacks, made visible`); loaded the desk fonts and `css/jeles-skin.css`
   after `css/styles.css`; added the `#jeles-deskbar` (back-to-desk link +
   author credit); loaded `js/jeles-progress.js` after `js/app.js`.
2. `css/jeles-skin.css` — **new file.** Overrides the Atlas palette custom
   properties to Ask Jeles' exact desk palette. The upstream `css/styles.css`
   is not forked.
3. `README.md` → `UPSTREAM-README.md` — the upstream README, kept for reference.
4. `js/app.js` — one additive block at the end of the IIFE exposing
   `window.KnowledgeMap` (`applyCompleted` / `getCompleted` / `toast`) so the
   bridge can seed completion without a reload. Upstream logic is untouched.
5. `js/jeles-progress.js` — **new file.** Fetches the local progress seed and
   unions it into completion; no-op when the file is absent.
6. `data/courses.json` — **new file.** A machine-readable index of the course
   catalog (id/title/field/topics/requires), generated by
   `scripts/export-courses.js`. It is a derivative of the CC BY-SA 4.0 course
   data and inherits that license.
7. `scripts/export-courses.js` — **new file.** Regenerates `data/courses.json`
   from `js/data/*.js`.

No changes to `js/data/**`. `data/jeles-progress.json` is user-private,
generated by `python -m askjeles.atlas_progress`, and gitignored — never
committed or hosted.
