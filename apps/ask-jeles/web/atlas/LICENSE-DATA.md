## Why this split?

The site's **code** is MIT-licensed (see [`LICENSE`](LICENSE)) so anyone can reuse
the engine freely. The **data** is CC BY-SA so the collectively built knowledge
map stays open: improvements and derivatives remain available to the community
under the same terms.

## A note on resources

The catalog **cites** external books, courses and notes; it does not reproduce
them. Those cited works remain under their own authors' and publishers'
copyright. Please contribute only factual descriptions, topic lists, and
citations — never copyrighted text pasted from a source.
