marching-arts — the checks Node cannot run

npm test covers the resolver, the predicate compiler, the schema and the owner protocol, all on the in-memory VFS. Three things it cannot cover, because Node has neither OPFS nor SharedWorker: the opfs-sahpool VFS itself, the Web Locks election, and the pauseVfs()/unpauseVfs() handoff. This page drives those. Serve it over http (not file:// — a null origin has no OPFS) and open it in two tabs for the handoff check.

What a pass here means

1  the SAH pool installed and a database opened on it: durability is real
2  the P1 gate holds against a file, not only against :memory:
3  every tab shares one owner: the second tab's count sees the first tab's writes
4  the pool was released and retaken without corruption: pauseVfs/unpauseVfs work
