# Store: Obsidian
b17: SAPS1

The Obsidian store — a provision-house for work built in Obsidian. Open, Apache-2.0.
Build in your own local space or a repo under the account; it stays yours until
it is **promoted** to a full SAFE app.

**Tools:** plugins · vaults · knowledge apps

**Scaffold / starter:** TBD — an Obsidian plugin starter to be provisioned

**Tiers** — same vocabulary as [`../README.md`](../README.md) and `CLAUDE.md`
- `stored/` — the **playground** tier's keeping record: provisional,
  incubating, contested (WIP, low bar). Not a copy of the code — the code
  lives in `apps/`; the record is what `stored/` stores.
- `promoted/` — full SAFE apps that cleared the bar (own repo, injected seams,
  tests, manifest, semantic-search seam over injectable knowledge). See the
  promotion bar in [`../README.md`](../README.md).

Obsidian is a knowledge platform — a natural fit for the semantic-search seam and injected document stores.
