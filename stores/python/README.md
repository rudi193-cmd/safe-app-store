# Store: Python
b17: SAPS1

The Python store — a provision-house for work built in Python. Open, Apache-2.0.
Build in your own local space or a repo under the account; it stays yours until
it is **promoted** to a full SAFE app.

**Tools:** Textual · Rich · CLI

**Scaffold / starter:** the generic TUI scaffold (Apache cut of tui-scaffold — to ship here)

**Tiers**
- `stored/` — provisional, incubating pieces (WIP, low bar).
- `promoted/` — full SAFE apps that cleared the bar (own repo, injected seams,
  tests, manifest, semantic-search seam over injectable knowledge). See the
  promotion bar in [`../README.md`](../README.md).

The store's current Python apps live in `../../apps/` and are the existing promoted tier; they will be indexed here as the layout settles. Nestor and Jeles graduated from this store into their own repos.
