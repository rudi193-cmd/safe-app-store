# Store: Python
b17: SAPS1

The Python store — a provision-house for work built in Python. Open, Apache-2.0.
Build in your own local space or a repo under the account; it stays yours until
it is **promoted** to a full SAFE app.

**Tools:** Textual · Rich · CLI

**Scaffold / starter:** the generic TUI scaffold (Apache cut of tui-scaffold — to ship here)

**Tiers** — same vocabulary as [`../README.md`](../README.md) and `CLAUDE.md`
- `stored/` — the **playground** tier's keeping record: provisional,
  incubating, contested (WIP, low bar). Not a copy of the code — the code
  lives in `apps/`; the record is what `stored/` stores.
- `promoted/` — full SAFE apps that cleared the bar (own repo, injected seams,
  tests, manifest, semantic-search seam over injectable knowledge). See the
  promotion bar in [`../README.md`](../README.md).

The store's Python apps live in `../../apps/` — the **playground** tier, not
promoted (promotion means extraction into its own repo with injected seams;
see `stores/promote_check.py`). All 23 are indexed: a real keeping record
exists for each under `stored/` (`docs/store_refit_plan.md` P1). Nestor and
Jeles graduated from this store into their own repos, ahead of this refit.
